## How to read this table

- Each career has exactly three proposed interests. The order follows the second review and has no effect on scoring.
- **Confidence** follows the second review:
  - High: close O*NET occupation, and the three interests agree with its interest code.
  - Medium: broader O*NET occupation, only the first interest type confirmed, or partial agreement.
  - Provisional: no O*NET code. The assignment is the author's judgement from the career record.
- **O*NET reference** gives the O*NET-SOC code, how closely it matches the career (close or broader), and the interest code read from O*NET OnLine on 2 November 2026.
- **Second review note** is the reviewer's comment on the first audit's draft, copied from the report.
- **Lecturer review status** is blank for the lecturer to complete (for example Approved, Amend, Reject).
- Related careers sometimes share all three interests. The second review accepts this as natural overlap, and this package does not change it. Skills (70% of the score) separate those careers.
