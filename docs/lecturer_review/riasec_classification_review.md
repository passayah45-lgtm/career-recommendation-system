# RIASEC classification review

Source: `docs/interest_taxonomy_second_review.md`, sections D and E, and the first audit `docs/skills_interests_audit.md`, section 6. The per-interest counts in section 3 below are a cross-tabulation of the second review's own tables (section C assignments and section E O*NET codes). They add no new O*NET evidence.

## 1. Purpose of RIASEC

RIASEC is Holland's model of six occupational interest types: Realistic, Investigative, Artistic, Social, Enterprising and Conventional. O*NET uses it to describe the interests that suit each US occupation. Each occupation gets a "high-point code" of one to three letters (the interest types with a standardized score of 50 or higher, according to the O*NET Web Services reference read by the second review).

For this project, RIASEC is useful in two ways:

1. **As a check.** If an occupation's O*NET code contains the type that an assigned interest belongs to, the assignment is consistent with independent occupational data.
2. **As a display aid.** Grouping 23 interests under six headings makes the assessment form easier to scan.

## 2. How the second review proposes to use it

- Each of the 23 interests has one primary type, with secondary types where the work clearly spans two (table below).
- The grouping is for display only. It does not enter the score.
- The second review checked each career's three interests against its O*NET code. An interest counted as consistent when its primary or a secondary type appeared anywhere in the code. Letter order was not used, because the O*NET pages read do not define it.

## 4. Classifications that remain uncertain

| Interest | Why it is uncertain |
|---|---|

| Designing apps, websites and user experiences | Artistic appears in only 3 of 6 coded careers. Software Developer, Web Developer and Instructional Designer pass only through the secondary Investigative link |

| Working with laws, rules and regulations | The second review marks it uncertain: no O*NET lawyer code is mapped, and both law careers (C057, C058) are provisional |
| Leading people and projects. Working with communities. Managing money and financial information | Only 1 to 2 coded careers each, too few to support or reject the placement |
| Caring for people's health | Biomedical Engineer (IRC) carries it without a Social code |

Other limits of the evidence (from section E of the second review):
- Codes were read from O*NET list pages with a web tool. Scores were not available, only letters.
- The O*NET pages read do not define letter order.
- 8 careers map to a broader O*NET occupation, so their evidence is weaker.
- O*NET describes US workers. No African occupational interest data was found.

## 5. Why RIASEC should stay a display aid and not a scoring component

1. **The formula is fixed.** Required skills 0.55, preferred skills 0.15, interests 0.25, education 0.05. A RIASEC score would add a new component or change the interest component, which is outside the approved scope.
2. **The grouping is an interpretation.** O*NET classifies occupations, not this project's interest terms. Section 4 shows that several placements are uncertain. Scoring on them would turn a judgement into a hidden weight.
3. **Coverage is incomplete.** 12 careers have no O*NET code, and 4 more have only the first letter. A RIASEC-based score would treat those 16 careers differently from the other 48.
4. **The evidence is US-based.** Interest patterns for the same job title in Guinea may differ.
5. **Display needs no scoring change.** Grouping the 23 interests under six headings helps students read the form without affecting any ranking.
6. **Any scoring use would need its own experiment.** It would need a new evaluation set (for example eval64_v2) and could not reuse the frozen eval64_v1 results.
